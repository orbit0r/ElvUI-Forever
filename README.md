# ElvUI Forever

**Version:** 1.0.0  
**Client:** World of Warcraft: Forever (`_classic_beta_`, Interface **16001**)

Personal Forever port of [ElvUI](https://github.com/tukui-org/ElvUI) (retail **v15.13** Mainline load path + Forever fixes).

**Not** an official Tukui / ElvUI release. Upstream authors have not shipped a Forever build.

## Install

1. Download this repo or the [Release](../../releases) zip.
2. Copy these three folders into `World of Warcraft\_classic_beta_\Interface\AddOns\`:
   - `ElvUI`
   - `ElvUI_Libraries`
   - `ElvUI_Options`
3. Restart Forever (`WowB.exe`) or `/reload`, and enable the addons.
